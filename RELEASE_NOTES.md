Bladesong Developer SDK 1.0.2

Standalone developer tooling for the stable Bladesong Framework API 1.0.0.

- JSON schemas, typed Lua API definitions, examples and mod templates.
- Portable packaging, manifest validation, and manual runtime overlay tools.
- Standalone UE4SS mod manifests can omit the framework API requirement.
- Ordinary SDK mods still declare their API range and framework dependency.
- The public API contract is unchanged and checked against the frozen API 1.0.0 definition.

This ZIP is for developers. It includes no game files, UE4SS binaries, framework runtime or mod manager.
